# NexaGrowth — Digital Growth & Technology Studio

A professional, responsive portfolio website for a fictional digital growth and technology studio.

## Purpose

This project demonstrates the ability to take a business concept from strategy to design to development. It showcases:

- Web Development (HTML/CSS/JS)
- Digital Marketing
- Business Strategy
- Market Research
- Product Thinking
- Technology Strategy

## Technologies

- HTML5
- CSS3 (with custom properties, flexbox, grid)
- Vanilla JavaScript (no frameworks)
- Google Fonts: Space Grotesk + Inter

## Features

- Fully responsive (mobile-first approach)
- Accessible (semantic HTML, ARIA, keyboard navigation)
- Dark/light professional aesthetic
- Mobile hamburger menu
- Smooth scroll navigation
- Intersection Observer scroll reveals
- Chart animation on scroll
- No external dependencies
