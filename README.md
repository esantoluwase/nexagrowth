## 🔄 Project Process

NexaGrowth follows a four-stage approach:

**Discover → Plan → Build → Grow**

### 01 — Discover

Understand the users, business goals, and underlying problem.

### 02 — Plan

Turn insights into a practical project roadmap and priorities.

### 03 — Build

Design, develop, test, and iterate the digital solution.

### 04 — Grow

Launch, learn from results, and identify the next opportunity.
